# Executive brief

> One page per phase for a non-technical sponsor (PURP-06). Plain language. **Simulated engagement, synthetic data.**
> Newest phase first.

## Phase 1: discovery and experiment design (Milestones 1–2, completed 2026-10-28)

**Outcome.** We know what to measure and how we'll decide. We wrote down, before building anything, which problems
the current loyalty support tools have, which fix should solve each one (better tools or AI), and what results would
count as a win.

**Evidence.**
- 25 likely problems, each with a predicted fix; our own prediction is that **most are fixed without AI**, and AI
  could help with about 1 in 8 requests (the messy ones: several stays in one message, other languages, receipts).
- Seven success tests, including a hard rule: no points may ever move twice or without a supervisor.
- These were locked in a dated record before any software existed, so results can't be bent to fit.

**Risks.**
- Everything so far is a simulation; the volumes and costs are assumptions.
- The person designing the test also builds the solutions. We reduce that risk by locking the design first and
  including cases where AI shouldn't help.

**Decisions needed now.** None. Later: approving a small budget for live AI tests (Milestone 8) and whether to host a
public demo (Milestone 12).

**Cost so far.** $0 in services. No AI usage yet.
