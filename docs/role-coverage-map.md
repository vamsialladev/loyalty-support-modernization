## Roles exercised by milestone
- **M1:** Security Engineer, Engineering Manager / Tech Lead, Technical Program Manager, QA, Staff / Principal (ADRs).
- **M2:** Forward Deployed Engineer, Product Manager, ML Engineer / Applied Scientist (experiment design), Solutions
  Architect, Security Engineer (threat model), Responsible AI (governance), Executive sponsor (brief).
- **M4:** Backend / Platform Engineer (mock service, idempotency, containers), QA (contract tests, fault matrix),
  Solutions Architect (swap table, mapping layer), Security Engineer (per-system roles, non-root read-only images, no
  labels in images), SRE (health and readiness).
- **M5:** Forward Deployed Engineer (customer workflow modelled credibly, legacy discovery mapped to defects), Backend /
  Platform Engineer (case tables, shared write path, reconciliation by key), Security Engineer (sign-in, sessions,
  CSRF, CSP, separation of duties), QA / Test Engineer (per-defect tests, Playwright end to end), Data Engineer
  (intake loader that never reads labels), ML Engineer / Applied Scientist (scripted agent with a fixed reading policy,
  no scoring before thresholds).
- **M3:** Data Engineer (generator, dictionary, checksums, mapping), ML Engineer / Applied Scientist (splits, leakage,
  re-weighting), QA (data tests, label cross-check), Responsible AI (fairness set), Forward Deployed Engineer (day-one
  analysis), Executive sponsor (phase 2 brief), Solutions Architect (swap path for real data).
- **M6:** Backend / Platform Engineer (job queue, worker, locks, four-step execution, reconciliation), Staff / Principal
  (RFC-0001, debt with triggers, scaling view), Security Engineer (keyed binding, role split, audit limits stated), SRE (graceful
  stop, kill switch, dead jobs), QA / Test Engineer (every state pair, differential test, real-process crashes, concurrency on
  real Postgres), Data Engineer (policy store, provenance, validation of missing, conflicting and stale data), Solutions
  Architect (the questions for a real platform's write API), Responsible AI / Governance (human approval bound to the exact
  action; publishing controls), ML Engineer / Applied Scientist (engine checked against the labeler on the dev split only).
- **M7:** Forward Deployed Engineer (each fix mapped to a pre-registered defect; arm-differences page), Backend / Platform Engineer
  (durable investigation, group limit under row locks, JSON API with a published contract), Frontend Engineer (the complete

  Staff / Principal (fence around the baseline, ADR-0063 and ADR-0064), Data Engineer (validation flags, day-one export with a trace
  test), Security Engineer (two identifiers, another member's data never stored, strict request bodies), Executive sponsor (phase 3
  brief), Solutions Architect (what arm B needs from a real platform).
- **M8:** ML Engineer / Applied Scientist (loop, harness, routing baseline with its rule committed first), Prompt Engineering (versioned prompt, separated data), Backend / Platform Engineer (provider port, worker integration, spend tables), Security Engineer (tool allowlist, injection tests on business effects, redaction, ingestion controls), Responsible AI / Governance (system card, use-case register, labelled AI text, evidence first), QA / Test Engineer (one test per stop condition), Staff / Principal (RFC-0002, the fairness call in ADR-0067), Data Engineer (document extraction with checks against the record).
